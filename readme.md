# Data-Driven Astronomy

This repository contains my personal solutions and code implementations for the **Data-Driven Astronomy** course by the University of Sydney (via Coursera).

## Overview
Developed by the University of Sydney (led by Associate Professor Tara Murphy and Simon Murphy), this intermediate online course teaches practical computational and programming skills using Python 3, SQL, database management, and machine learning applied to real astronomical datasets
